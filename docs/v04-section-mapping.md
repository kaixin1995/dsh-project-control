## 与总纲字面差异汇总（共 3 处，均有已验证依据）

1. **§21/§86 首页优先**：本体默认落地视图硬编码（`DEFAULT_VIEW_ID='chat'`），仓外无破坏性改法 → 实现为「项目认知」页签一键直达 + 侧边仪表盘。
2. **§32 Plan / §36–43 执行体系**：本体已有 plan-mode、多步长任务、断点 resume、llm-retry → 插件引用/聚合/编排，不重建（否则违背仓外插件权限面并重复建设）。
3. **§11 历史分析成本**：逐 commit 详析不可行 → L0–L3 分层预算（事实零成本、全量轻析、启发式聚类、重点详析）。
